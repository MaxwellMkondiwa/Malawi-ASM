# Malawi Agricultural Sector Model [Malawi-ASM] 

## Running GAMS code

The GAMS file “Malawi Ag Sector Model_BaselineV2.gms” implements the price endogenous sector model described in the paper. You need to change the path in your computer to run the GAMS model. If you open the GAMs program using the project "MalawiFoodModel.gpr", you do not need to change any paths. 

The .INC files are data files which are used in the model.
